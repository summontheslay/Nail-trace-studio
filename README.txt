Nail Trace Studio — installable web app package

Upload all files in this folder together to an HTTPS static web host (e.g. GitHub Pages or Netlify). Open the resulting HTTPS address in Chrome on Android. Use Chrome menu > Add to Home screen / Install app. After first load, the app shell can work offline. Opening index.html directly as a local file will not enable PWA installation or the offline service worker.

This package is not an APK. Android system gestures are not disabled by the tracing lock. Calibrate physical measurements with a ruler before tracing.
